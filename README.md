# dynamic-bot-bilibili

Bilibili 动态源插件，用于让 dynamic-bot 订阅 Bilibili UP 主的动态和直播状态，并支持解析 Bilibili 链接。

主项目：[dynamic-bot](https://github.com/Colter23/dynamic-bot)

## 功能

- 添加订阅时支持 UID 和用户名搜索。
- 检测 UP 主的新动态。
- 检测直播开播和下播。
- 解析动态、视频、直播间、用户空间和 b23.tv 短链接，视频链接可选择下载视频。
- 可在订阅时自动关注 UP 主。
- 遇到未登录或风控时自动暂停轮询，避免持续请求。

## 安装

构建插件：

```powershell
.\gradlew.bat fatJar --offline
```

把生成的 `*-all.jar` 放入主程序的 `plugins/` 目录，然后启动或重启 dynamic-bot，在后台启用插件。

## 登录

在后台的“平台登录”页登录 Bilibili 账号，支持二维码和 Cookie 两种方式，推荐用二维码。

登录状态会被保存，运行中 Cookie 被刷新时也会尽量自动回写。登录失效时轮询会暂停，重新登录后恢复。

## 配置项

大多数情况保持默认即可。

- `轮询间隔`：多久检查一次动态和直播状态，默认 30 秒。
- `接口请求间隔`：连续请求 Bilibili 接口之间等待多久，默认 0.5 秒。
- `直播检测`：是否推送开播和下播。
- `关注分组名称`：自动关注时加入哪个 Bilibili 关注分组。
- `补发时间窗口`：启动时是否补发最近动态，默认 0（不补发）。
- `风控暂停时长`：检测到请求被拦截后暂停多久。

不建议把轮询间隔设置得很短，访问越频繁越容易触发风控。

## 订阅

在主程序后台添加发布者时，可以输入 Bilibili UID 或 UP 主用户名。搜索到发布者后，选择要推送到的 QQ 群或好友即可。

如果开启了主程序的“订阅时自动关注”，插件会尝试自动关注该 UP 主。

## 链接解析

支持动态、视频、直播间、用户空间和 b23.tv 短链接。

如果链接解析模板里包含视频占位符，视频链接会尝试下载并发送视频。视频大小上限为 0 时表示不限制。

## 使用建议

- 首次使用先完成登录，再添加订阅。
- 保持默认轮询间隔，除非确实需要更快检测。
- 订阅很多 UP 主时，优先提高轮询间隔来减少请求量。
- 经常出现风控提示时，增大请求间隔或暂停一段时间。
